# P3 ECG 通道设计（AD8232 + ADC/DMA）（2026-09-22）

> 目标：在已有 PPG 链路之外，把 **ECG 通道**打通，并用「两条链路互相验证」的方式证明整条采集链路可靠
> ——同一时刻的 PPG 心率与 ECG 心率应当一致，这是最有说服力的现场证据。

## 一、为什么加 ECG

1. **验证手段**：PPG 心率没有独立真值；有了 ECG，两条独立链路互相校验（同段数据偏差应 <5 bpm）。
2. **岗位相关性**：可穿戴/医疗类 JD 常同时要求 PPG 与 ECG（心率、HRV、房颤筛查都依赖 ECG）。
3. **成本低**：AD8232 模块约 25 元，MCU 侧只用 ADC + 定时器 + DMA。

## 二、硬件与信号链

| 环节 | 选择 | 理由 |
|---|---|---|
| 前端 | AD8232 单导联心电模块 | 集成仪表放大器、右腿驱动、0.5–40 Hz 带通与快恢复；模拟输出直接进 ADC |
| 电极 | 三片一次性电极（RA / LA / RL） | 单导联即可满足 QRS 检出 |
| 采样 | **定时器触发 ADC + DMA**，250 Hz | QRS 主能量 5–15 Hz，按奈奎斯特 ≥30 Hz；工程上取 250 Hz 便于定位 R 波与计算 RR |
| 供电 | **仅电池**（或确保整机浮地） | 人体接触测量的安全红线：不要一边接市电 USB 一边贴电极 |
| 导联脱落 | AD8232 的 LO+ / LO− 接普通 GPIO | 脱落时输出高，固件上报 `ECG_LEAD_OFF` 事件而不是把噪声当心搏 |

采样率为什么是 250 Hz 而不是跟 PPG 一样 100 Hz：
QRS 上升沿很陡（宽度约 80–100 ms），100 Hz 只有 8–10 个采样点描述整个 QRS，R 波定位误差会明显放大 RR 精度；
250 Hz 有 20–25 个点，配合 5 点差分能稳定定位。这也是 TI TIDA-01580 一类参考设计的常见档位。

## 三、固件结构（对应已实现的模块）

```
TIM 触发 → ADC+DMA（半满/全满中断）→ 环形缓冲
   → ecg_algo_push()（firmware/app/ecg_algo.c：5–15 Hz 因果带通 → 5 点差分 → 平方 → 150 ms 积分 → 双自适应阈值 → RR 中位数）
   → 上报：ECG_BATCH 原始波形帧（可选）+ STATUS/LOG 中的心率与质量
```

- `firmware/app/ecg_algo.c` **已实现并验证**（`tests/test_ecg_conformance.py`：合成信号偏差 0.0 bpm，BIDMC 真实 ECG 窗口偏差 0.0–1.1 bpm）。
- 只支持 **125 / 250 Hz**（±10%），其他采样率明确失败（不静默用近似系数）。
- 与 PPG 共用 `firmware/app/biquad.c`（同一种二阶节实现，只是系数不同）。

## 四、双通道一致性验收（P3 的核心指标）

| 项 | 标准 | 证据 |
|---|---|---|
| ECG 波形 | 静息下能稳定看到 QRS，R 波幅度 > 0.3 mV | 上位机波形截图 |
| ECG 心率 | 与 PPG 心率在同一 30 s 窗口内偏差 ≤5 bpm | 对照表（脚本复用 P0 的验证代码） |
| 导联脱落处理 | 拔掉电极时上报 `LEAD_OFF`，不输出心搏 | 串口日志 + 记录 |
| 运动伪影 | 走动时质量判定为不可信（而不是给出错的心率） | 质量字段与波形对照 |
| 同步性 | PPG 与 ECG 的时间戳对齐误差 ≤10 ms | 双通道同图 + 时间戳差 |

## 五、与 PPG 的冲突与规避

- **供电噪声**：MAX30102 的 LED 是脉冲电流，会在电源上造成纹波并串入 ECG。对策：LED 与 AD8232 分开供电轨/加强去耦；必要时**分时采集**（PPG 与 ECG 交替，而不是同时）。
- **共地**：两块模块共地时，LED 脉冲电流在地线上的压降会被 AD8232 放大。对策：单点接地、缩短回流路径。
- **人体工频干扰**：50 Hz 及其谐波会进 ECG。AD8232 内部已滤除多数，仍残留时用固件的 50 Hz 窄带陷波（`biquad` 直接复用，加一组系数即可）。

## 六、上机顺序

1. 只接 AD8232、不贴电极：手碰输入端应看到明显 50 Hz —— 说明模拟通路通了。
2. 贴电极（电池供电）：看 QRS 是否可辨识；同时看 LO+ / LO− 状态。
3. 提高采样率与看逻辑分析仪：确认 TIM 触发 ADC + DMA 的周期稳定（抖动 <1%）。
4. 双通道同时采集 5 min：导出 CSV，按第四节验收。
5. 把实测结论与波形归档到 `docs/04-调试记录.md`。
