# 信号处理笔记（PPG / ECG）

> 这份笔记的目标：把「参数为什么是这么定的」讲清楚。面试里被问「你这个滤波器怎么选的」时，
> 能直接答出**信号带宽 → 采样率 → 滤波器阶数与截止频率 → 峰值检测阈值策略**这条推理链。

## 一、PPG（光电容积脉搏波）

### 1. 信号构成
PPG 原始信号 = **DC**（组织、静脉血、骨骼的稳定吸收）+ **AC**（随心脏搏动的动脉血容积变化）+ 干扰。

| 成分 | 频率范围 | 相对幅度 | 处理方式 |
|---|---|---|---|
| 心搏 AC | 0.5–5 Hz（30–300 bpm 基频与谐波） | 0.5–5% of DC | 保留（这是有用信号） |
| 呼吸调制 | 0.15–0.5 Hz | 可比心搏更大 | 高通/带通下限压掉 |
| 运动伪影 | 0.1–10 Hz，与心搏重叠 | 不定 | 靠质量指标识别 + 拒绝，而不是靠滤波「修好」 |
| 工频/环境光 | 50 Hz / 直流 | 不定 | 传感器内部机制 + 采样率设计 |

**关键认识**：运动伪影和心搏在频域上重叠，**滤波无法分离**。正确做法是识别（PI、模板相关性）并**拒绝该段数据**，这也是本项目质量门限的来由。

### 2. 参数选择的理由
- **带通 0.5–4 Hz**：下限 0.5 Hz（30 bpm）覆盖极端心动过缓并压掉呼吸漂移；上限 4 Hz（240 bpm）覆盖运动心率上限，同时把高频噪声压掉。
- **零相位滤波（filtfilt）**：离线分析用，避免相位延迟导致峰位偏移；**真机上不能这么做**（需要因果滤波），真机用 2 阶 Butterworth 单向滤波并接受固定群延迟，文档里要说明这个区别。
- **滑动窗口自适应阈值**：阈值为「窗口内中位数 + k·1.4826·MAD」。用中位数/MAD 而不是均值/标准差，是为了抗离群点（一次运动伪影会把均值拉飞）。
- **k = 0.6**：经验值。k 大 → 更保守（漏检）；k 小 → 更容易把舒张期切迹当峰。真机上应按 PI 动态调整。
- **min_distance = fs·60/220**：由最大心率 220 bpm 推出最小 RR，防止把同一个心搏的双峰当一个。

### 3. 质量指标
| 指标 | 定义 | 阈值 | 含义 |
|---|---|---|---|
| PI（灌注指数） | AC<sub>pp</sub>/DC × 100% | > 0.05% | 信号强度；太低说明没贴合/灌注差 |
| 模板相关性 | 逐搏波形与平均模板的相关系数均值 | > 0.6 | 形态一致性；运动伪影会显著拉低 |
| 心搏数 | 有效 RR 个数 | ≥ 3 | 样本太少不给结论 |

## 二、心率与 HRV
- **心率取 RR 中位数**而非均值：单次漏检/多检对中位数影响小。
- **RR 有效范围 270–2000 ms**（30–220 bpm），超出的直接判为误检。
- **SDNN/RMSSD** 是 HRV 的两个基础指标；本项目在 30 s 窗口上给出，注意短时 HRV 的可比性有限。

## 三、SpO2（ratio-of-ratios）
1. 红光（660 nm）与红外（940 nm）的 AC/DC 之比分别为 R<sub>red</sub>、R<sub>ir</sub>。
2. 定义 R = R<sub>red</sub> / R<sub>ir</sub>。R 越大 → 血氧越低。
3. 经验标定曲线（本项目内置两条，均来自公开参考实现）：
   - 线性：SpO₂ = 110 − 25R
   - 二次：SpO₂ = −45.06R² + 30.354R + 94.845

**为什么只能算「方法验证」**：标定系数依赖具体光学结构（LED 波长、光电二极管、探头几何）与个体差异，**必须用参考血氧仪在同一批人上标定**。本项目没有做标定，所以输出只用于验证链路与 R 值的稳定性。

## 四、ECG 与 QRS 检测（Pan–Tompkins 简化版）
1. **带通 5–15 Hz**：QRS 的主要能量在 5–15 Hz；这样能压掉 P/T 波（低频）与肌电（高频）。
2. **微分**：突出 QRS 的陡峭斜率。
3. **平方**：全部变正并放大高斜率成分（同时放大噪声，靠积分平滑）。
4. **150 ms 滑动积分**：得到平滑的包络，宽度匹配 QRS 时宽。
5. **自适应阈值 + 200 ms 不应期 + 回检**：
   - SPKI（信号峰估计）= 0.125·peak + 0.875·SPKI，NPKI（噪声峰估计）同理；
   - 阈值 = NPKI + 0.25·(SPKI − NPKI)；
   - 200 ms 不应期内只保留更高者（生理上不可能有 300 bpm）；
   - 两次心搏间隔 > 1.66×RR 中位数时回检一次，避免漏检。

**简化的地方（如实说明）**：未实现论文中的波形判别（基于斜率/宽度的 QRS 与噪声峰分类）与迭代回检，因此在高噪声下灵敏度会下降；真机上加运动场景数据后再补。
