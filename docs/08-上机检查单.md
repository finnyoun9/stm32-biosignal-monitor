# 上机检查单（现象 → 假设 → 实验 → 结论）

> 用法：上机时遇到现象，**先查这张表**，按顺序做实验；每条实验都要留下数据（串口日志/CSV/示波器截图）。
> 本表是 `docs/04-调试记录模板.md` 的**预填版**——把最常见四类坑的假设先写好，你现场只需记录"哪条成立"。
>
> 采完数据先跑一页体检：`./.venv/bin/python tools/inspect_capture.py --ppg ... --ecg ... --out docs/img/capture-report.md`

## 现象 1：`max30102 init failed`（I2C 没通）

| # | 假设 | 实验 | 判据 |
|---|---|---|---|
| 1.1 | 供电没上 / 电平不对 | 万用表量模块 VIN 与 GND | 应为 3.3 V；若 5 V → 立即断电改接 |
| 1.2 | SDA/SCL 接反或没接 | 目视 + 万用表通断 | SCL→PB6、SDA→PB7；模块上拉电阻在位 |
| 1.3 | 上拉缺失/过强 | 量 SDA 对 3.3 V 的静态电阻 | 4.7 kΩ 量级正常；<1 kΩ 会拉低波形 |
| 1.4 | I2C 地址不对 | 写一个 I2C 扫描（遍历 0x08–0x77） | 应看到 **0x57** |
| 1.5 | 器件是别的型号 | 读 `PART_ID`(0xFF) | MAX30102 = **0x15**；0x11 是 MAX30100、0x15 之外都要换驱动 |
| 1.6 | 时钟配置错（CubeMX） | 量 SCL 频率 | 100–400 kHz；若为 0 说明 I2C 外设没初始化 |
| 1.7 | 电源纹波导致通信偶发失败 | 示波器看 VIN 纹波，串口统计 CRC/失败次数 | 纹波 >100 mV → 加 10 µF + 0.1 µF 去耦 |

**结论填写位置**：`docs/04-调试记录.md` 第 1 条（现象 → 命中哪条假设 → 修改 → 复测结果）。

## 现象 2：能读到数据但 **PI 极低**（<0.05%）或心率跳变

| # | 假设 | 实验 | 判据 |
|---|---|---|---|
| 2.1 | 手指没贴好/漏光 | 遮住模块、换手指按实 | PI 应明显上升；遮光后 PI 掉到 0 属正常 |
| 2.2 | LED 电流太小 | 把 `max30102_set_led_current()` 从 0x33(≈10 mA) 提到 0x7F(≈25 mA) | PI 上升且心率更稳；注意发热与耗电 |
| 2.3 | ADC 量程/脉宽配置不合适 | 改 `SPO2_CONFIG` 的 ADC 量程（2048/4096/8192/16384 nA）与脉宽 | 波形不饱和（不贴顶）且幅度够大 |
| 2.4 | 采样率与积分时间冲突 | 检查 SR 与 PW 组合是否被 `pw_fits_sr()` 拒绝 | 初始化应返回 false 而不是"能跑但数据乱" |
| 2.5 | 阈值过松把舒张期切迹当峰 | 把 `tests` 里的 k 从 0.55 提到 0.8 再采一段 | 心率下降并稳定（这是 PPG 侧最典型的误检） |
| 2.6 | FIFO 读取不及时丢样本 | 看 `tools/inspect_capture.py` 的"时间戳空隙"与 STATUS 的溢出计数 | 有空隙/溢出增长 → 缩短读取周期或改用 INT 驱动 |

## 现象 3：`fifo_overflows` 持续增长（采集跟不上）

| # | 假设 | 实验 | 判据 |
|---|---|---|---|
| 3.1 | 读取周期 > FIFO 深度 / 采样率 | 100 Hz、深度 32 → 理论 320 ms 必须读一次；当前 `AcqTask` 是 100 ms | 加大余量：把读取周期设到理论值的 1/3 以内 |
| 3.2 | 读 FIFO 的 I2C 事务太长 | 逻辑分析仪量一次读 6×N 字节的耗时 | 400 kHz 下 60 字节 ≈ 1.5 ms，若明显更长 → 检查时钟拉伸 |
| 3.3 | 采集任务被算法/打印阻塞 | 逻辑分析仪抓 INT 与读取时刻；或在 `AcqTask` 打时间戳 | 采集任务里不允许做运算与阻塞打印（当前实现只入队） |
| 3.4 | 队列满后丢最旧样本 | 看是否触发过"队列满"分支 | 若频繁触发 → 提高 ProcTask 优先级或缩短算法耗时 |
| 3.5 | 中断丢失 | 打开 A_FULL 中断并统计中断次数 vs 样本数 | 两者应成比例 |

## 现象 4：**ECG 50 Hz 工频干扰** / 波形毛刺

| # | 假设 | 实验 | 判据 |
|---|---|---|---|
| 4.1 | 供电地环路（USB 与人体形成回路） | 改用电池供电再测 | 干扰显著下降 → 以后人体接触测试一律电池供电 |
| 4.2 | 电极贴放/接触阻抗差 | 重新贴电极、清洁皮肤 | 波形幅度稳定、基线漂移减小 |
| 4.3 | 导联脱落误判为心搏 | 拔掉电极看 LO+ / LO− 状态与固件行为 | 应上报 `LEAD_OFF` 并停止输出心率，而不是给出噪声心搏 |
| 4.4 | 50 Hz 及其谐波残留 | 打开已实现的陷波：`ecg_algo_init_opt(&algo, fs, true, 50)`（`firmware/app/notch.c`） | 陷波深度实测 −95 dB 量级；**强干扰（幅度 ≥2× R 波）时从「检出失败」变为正常出心率**，见 `tests/test_notch_ecg.py` |
| 4.5 | PPG 的 LED 脉冲电流串入 ECG | 分时采集（PPG/ECG 交替）或分开供电轨再测 | 若分时后干净 → 说明是电源/地耦合，按 `docs/07` 第五节处理 |
| 4.6 | 采样率不足导致 R 波定位抖动 | 250 Hz 与 500 Hz 各采一段对比 RR 标准差 | RR 标准差应随采样率提高而收敛；250 Hz 已满足 QRS |

## 通用记录要求（每条现象都必须写全）

1. **现象**：可观测、带数字（"心率在 90–130 之间跳，30 s 标准差 12 bpm"），不写"效果不好"。
2. **假设**：从上面表里选，注明第几条。
3. **实验**：做了什么改动、看什么数据。
4. **结论**：支持/否证哪条假设；**修改了什么**；**复测数字**。
5. **证据文件**：CSV 路径、波形图路径、逻辑分析仪截图路径。
6. **回归**：`./tests/run_all.sh` 仍全绿（离线部分不受影响）。
