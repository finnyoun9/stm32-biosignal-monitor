# 硬件选型与接线

> 选型原则：**用手上已有的板子 + 两个常见模块**，把预算压到 50 元以内，同时保证每个选择都能讲出理由。

## 一、BOM

| 部件 | 型号 | 价格 | 为什么选它 | 备注 |
|---|---|---|---|---|
| 主控 | STM32F103C8T6（蓝板，已有） | — | 手上有；Cortex-M3、I2C 硬件外设、DMA 齐全，够跑 RTOS + 算法 | 也可换已有的 F407VET6 最小系统板（DMA/定时器更充裕） |
| PPG 传感器 | MAX30102 模块 | 10–20 元 | 集成 LED + 光电二极管 + 18 位 ADC + FIFO，I2C 接口；可穿戴/健康类岗位的最常见器件 | 模块自带 1.8V/3.3V 电平与去耦，注意别买成 MAX30100 |
| ECG 前端（P3） | AD8232 模块 | ~25 元 | 单导联心电前端，模拟输出直接进 ADC；TI 参考设计 TIDA-01580 用的是同类方案 | 需要电极片；**只用电池供电时更安全** |
| 调试 | ST-Link V2 + USB-TTL | 已有 | 下载 + 串口波形 | USB-TTL 用于 115200 波特率输出 |

## 二、关键选型理由（面试会被问）

1. **为什么 MAX30102 而不是 MAX30100/MAX86150？**
   MAX30102 的 FIFO 与寄存器文档齐全、社区参考多；MAX30100 已停产且 FIFO 有已知缺陷；MAX86150 集成 ECG 但价格高、采购难。做「采集链路」这一层，MAX30102 的性价比最高。

2. **为什么 PPG 用 I2C，而 ECG 用 ADC？**
   MAX30102 内部已经完成光电转换与 18 位 ADC，输出数字量走 I2C；AD8232 输出的是模拟电压，必须用 MCU 的 ADC 采样，因此 ECG 通道要额外关注**采样率与定时器触发的确定性**（不能用软件轮询）。

3. **为什么 PPG 采样率定 100 Hz？**
   PPG 有效带宽约 0.5–5 Hz（心率 30–300 bpm 的基频与谐波），按奈奎斯特至少 10 Hz；但要做峰值定位和形态分析，工程上取 50–100 Hz（Maxim 参考设计常用 50/100 Hz）。本项目默认 100 Hz，可在协议里配置。

4. **LED 电流怎么定？**
   MAX30102 的 LED 电流（0–51 mA，步进 0.2 mA）直接决定信号幅度与功耗：太小信噪比不够（PI 低、峰检不稳），太大发热且耗电。真机上做**两级策略**：先用中等电流（约 7–10 mA）采一段，按 PI 调整后再进入连续采集。

## 三、接线

详细的引脚级接线表见 [`hardware/wiring.md`](../hardware/wiring.md)。要点：

- **MAX30102 是 3.3 V 器件**，模块 VIN 接 3.3 V；若模块带电平转换可接 5 V，但仍建议 3.3 V 以统一电平。
- I2C 上拉：模块一般自带 4.7 kΩ；若与其它 I2C 器件并联，注意等效上拉不要过强（< 2 kΩ 会导致上升沿过快、EMI 变差）。
- **电源去耦**：MAX30102 的 LED 驱动是脉冲电流，电源纹波会直接进信号。模块旁边加 10 µF + 0.1 µF，且走线尽量短——这也是「信号质量差」最常见的原因之一。
- **AD8232 与人体接触**：只用电池供电（或确保整机浮地）做人体接触测量；不要用接市电的 USB 供电同时贴电极，属于安全红线。

## 四、上机前检查清单

- [ ] 万用表确认 3.3 V 供电正常、模块无发烫
- [ ] I2C 扫描（0x57 = MAX30102 写地址 / 0xAE 读地址）能读到器件
- [ ] 读 Part ID / Revision ID 寄存器确认芯片型号
- [ ] 串口能收到 STATUS 帧（含 LED 电流、采样率、丢包计数）
- [ ] 逻辑分析仪抓一次 I2C 读 FIFO，确认 SCL 频率与数据长度符合预期
- [ ] 手指贴合后 PI 明显上升；离开后质量判定为「无效信号」
